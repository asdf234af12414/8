# 이미지 생성 및 제조결함 데이터 생성 실습

본 저장소는 Stable Diffusion과 AnomalyAny를 활용한 실습 과제 제출물입니다. 실행 코드, 결과 이미지, 추가 실험과 분석을 두 개의 노트북에 정리했습니다.

## 파일 구성

| 파일 | 주요 내용 |
|---|---|
| 8-1 노트북 | 텍스트 기반 이미지 생성, 인페인팅, 마스크 크기에 따른 객체 생성과 배경 보존 비교 |
| 8-2 노트북 | 정상 이미지 기반 결함 생성, PCB의 조건값·상세 프롬프트·마스크 적용 비교 |

## 주요 결과

- 8-1: 마스크 크기에 따라 보물상자 생성과 주변 장면의 변화가 달라졌다. 상자는 생성됐지만 ‘모래에 묻힌 모습’은 충분히 구현되지 않았다.
- 8-2: 마스크 적용으로 원본 구조의 보존은 개선됐으나, 목표한 PCB 균열은 명확하게 생성되지 않았다.

## 실행 환경

Google Colab의 GPU 환경에서 실행했습니다. 설치 및 실행 과정은 각 노트북에 포함돼 있습니다.
